# Level (.tlb.yc) format and baking (Mina the Hollower)
Tools: tools/tlb.py (reader), tools/bake_levels.py (PNG+JSON), tools/xref.py (adrp xref scanner). Output: _levels/ (per level: .png class map RGBA, _preview.png on dark bg, _art.png grayscale tile art, .json mapping; index.json; area_hashes.json).
Run: python tools/bake_levels.py "<data dir>" _levels [name-substr]   (54 of 99 tlb files bake; the rest have no collision layers: bigArt, panorama, cutscenes)

## VERIFIED (disassembly of the record-def builders at 0x10014bb68.. / 0x10016bbcc.. + data checks)
- YCD array header u64: count = h>>34, capacity = (h>>4)&0x3fffffff; then u64 pointer. Strings: u64 (len<<32) + ptr.
- Root (ycTileLevel2Def) at root offset 0x100: u32 levelW,levelH (500x500 tiles), tileW,tileH (8,8 world units per tile), chunkW,chunkH (16,16); arrays at +0x18 props, +0x28 roomBounds (Geometry, 64 B), +0x38 tileLayers (168 B), +0x48 entities (88 B), +0x58 markers, +0x68 splines, +0x78 tileInfo (6 B), +0x88 textures (40 B), +0x98 uniqueEntityTypes, +0xa8 collisionTiles.
- Room (Geometry, 64 B): props array @0 (24 B props: u32 keyhash,pad,string value; key hash function not identified), nameHash, nameLevelHash, flags, center f32 x,y @0x2c/0x30 (world, y up, NEGATIVE y), half... w,h @0x34/0x38 are FULL width/height (AABB = center +-w/2,h/2; checked against rooms overlay).
- TileLayer (168 B): name string @16, palette names @48, usedTextures @64, chunkStart array(u32) @80 (chunk grid = ceil(wt/16) x ceil(ht/16) row-major; value = tile offset into decoded data, 0xffffffff = empty chunk), position f32 x,y @104 (layer-frame, y DOWN), parallax @112, widthInTiles @128, heightInTiles @132, collisionLayer u32 @136 (1 = collision layer), depth f32 @140, tileData @152 = {u64 compressed size, ptr} WFLZ blob -> u16 per tile, chunk-major (16x16 tiles per chunk, row-major inside). Cell value v: 0 = empty; tileInfo index = (v & 0x3fff) - 1; bit 0x4000 / 0x8000 = flips.
- TileInfo (6 B): u16 textureIndex (0, or 0xFFFF = animated), u16 tileIndex (into the 8x8 atlas), u16 collisionType.
- Texture (40 B): u32 w,h,tileW,tileH, ..., {size, ptr} WFLZ -> 8-bit palette-index atlas (e.g. 2048x32). _art.png renders it (indices x5, gray; palette not applied) and visually matches a real map of the level.
- collisionType -> kCollisionDef[47] (Mach-O 0x100d4d9f8, 48 B = 3 kinds x {u32 shape,u32,u64 mask}). Kind 0 is always tested by physics, kind 1 only for entities with query flags 0x600/0xa00. Types with kind0 shape != 0 (7..31,45) = solid walls (confirmed on art: walls, trees, building, fences are red in my overlay). Type 1 = kind1 only, mask 1, where the real walkable ground sits (confirmed on art). Types 32..44, 2..6 kind1-only other masks (pit/stairs/special; stairs confirmed light, pits dark). Type 0 = decoration only (no collision).
- EXTRA_COLLISION* layers are invisible limits (type 32 painted over floors); bake_levels ignores their non-wall tiles.
- Coordinates: SpawnManager::CreateSpawnPoint (0x100acdfc0) uses world = (entity.x * 1.0, -(entity.y * 1.0)). Tile layers and entities are in the same y-down frame; world y = -layer y. Rooms already in world (y up). Tile (col,row) of a layer covers world x = layer.x+8*col .. +8, y = -(layer.y+8*row) .. -8. All levels share ONE global frame (e.g. cryptA x 1900..3400, y -1600..-480; hub_overworld_south x 940..3600, y -5100..-3600), no per-level origin transform was found; origin in JSON = world coords of PNG top-left: px=(wx-origin_wx)*px_per_unit, py=(origin_wy-wy)*px_per_unit (px_per_unit = 1.0 at SCALE 8/tile 8).
- Area id: hashlittle(name, seed 1337) confirmed: 0x6e578e4f = "OverworldSouth" (the earlier note). Level m_nameLevelHash-style fields are hashes of layer names too (0x11d27e63 = "FOG_BORDER2"). Known area names (third item of the GAMESTATE table in __cstring, e.g. "Hub Overworld South | OverworldSouth | level_hub_overworld_south | levels/overworld/hub_overworld_south") hashes are in _levels/area_hashes.json.
